01

The Python stack

Python is the lingua franca of geospatial analysis. GeoPandas extends the DataFrame with geometry; Shapely handles geometric operations; Rasterio reads and writes raster grids; pyproj manages coordinate systems. Together they cover most day-to-day GIS scripting.

import geopandas as gpd

# Read a vector layer and reproject to Web Mercator
gdf = gpd.read_file("naxos_landforms.gpkg")
gdf = gdf.to_crs(epsg=3857)

# Spatial join: which landforms fall inside each survey area
joined = gpd.sjoin(gdf, survey_areas, predicate="within")
print(joined[["landform", "area_name"]].head())

02

Spatial databases — PostGIS

PostGIS turns PostgreSQL into a spatial database: geometry and geography types, spatial indexes, and hundreds of functions for measurement, overlay, and topology. Analysis moves next to the data, so queries stay fast even at national scale.

-- Find all sample points within 500 m of the coastline
SELECT p.id, p.name
FROM   samples   AS p
JOIN   coastline AS c
  ON   ST_DWithin(p.geom, c.geom, 500)
ORDER BY p.id;

03

Desktop, CLI & cloud-native

ArcGIS Pro — Esri's industry-standard commercial suite — and QGIS — its open-source counterpart — are the two desktop GIS environments for cartography and interactive analysis; GDAL/OGR is the translation layer beneath almost every GIS tool, converting between hundreds of raster and vector formats. Cloud-native formats — Cloud-Optimized GeoTIFF and the STAC catalog specification — let analysis stream imagery straight from object storage without downloading whole scenes.
